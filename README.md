# NotZeke News

A personal news feed that learns what Zeke wants to read, with a simple interface inspired by Hacker News.

This repository currently contains a build proposal only. No application, crawler, telemetry collection, or deployment has been implemented.

Read the [build proposal](docs/build-proposal.md) for the product scope, proposed architecture, learning loop, and implementation milestones.

The first version will start with a small set of sources and examples supplied by Zeke. Future implementation will add a scheduled collection agent, personalized ranking, interaction tracking, and an “I wish I had seen this” link submission flow.
